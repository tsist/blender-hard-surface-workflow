# 从控制笼制作硬表面

本技能的原生布线、曲面和面板流程基于 Windows Blender 5.3.0 与 Hard Surface Workflow 0.3.5。标有 `blenderctl` 的批处理及回退实例依赖配套工作区版 0.91.0。案例正文保留实测方法与读数，本地工程和原始审计文件由工作区保管。

当前建模、工具适配和验收统一使用 Windows Blender 5.3.0。先读已有工程的版本和父锚点，在 5.3.0 工作件中冷开并复测实际修改器和受保护区。

**控制笼**是细分前直接编辑的少量点、边、面。**母面**是承接开口、折边或接缝的主曲面。**截面**是用一个平面切过模型看到的真实轮廓。先用少量控制点做出主要形状，能说清一圈线负责哪个转折、开口或缝，再决定是否加线。

## 接到新件时

1. **先读形和尺度。** 复杂产品用至少两个不同方向的正投影（无透视缩短的视图），如正视加侧视，共用原点、比例与地标。补一张无遮挡斜视，认清外皮、内侧、参考叠影和邻件遮挡。深度若只能由画面估读，保留估读范围。简单试片只需给定视距、截面和改形动作。[读形、分件与工序](references/complex-surface-plan.md)
2. **先定每道缝两侧是谁。** 固定装配基准，确认固定壳、活动片、独立嵌件与取件方向。连续外形可先连体起坯再开真实缝，也可以单独起坯后装配。用邻件原位的轮廓和剖面检查两侧是否接得上。
3. **用宽面做出大形，给孔口留位置。** 从少量关键截面或基本体起步，先顺好肩线、握位和外缘。位置已知的孔口可从起稿保留一圈稀疏边；孔壁、底和细转折等母面稳定后再定。镜像可共用对称的一半，Simple（只增加面片的细分方式）可在确需更多布线位置时使用。应用修改器前保存可编辑的前一版。[工序和加线取舍](references/mesh-flow.md#从读形到开孔的工序)
4. **确认接到哪，再动刀和折边。** 在源笼中实际选中并核对起点、终点、邻面和移动方向。刀切要确实拆开原面。返边（壳口向里折回的窄面带）与跨折槽按每段实际方向来做，段间共用一条连接边。先看口、壁、底和邻件，再给转折加卡线（让细分后的圆角收在指定位置的边）。[翻边和实选](references/mesh-flow.md#沿开口续接翻边)
5. **同机位看外形、缝和光。** 在固定装配姿态核源笼、保存时真正启用的修改器，以及需要的 Catmull–Clark 一、二级细分（把网格过渡成光滑曲面的算法）。同一位置看轮廓、剖面和横纵两向条光（用长条反光显出曲面起伏）。圆角过软先试局部滑动卡线，挤痕先回查接线、截面和线距。降一档或去一圈时，按看得见的效果和改型能力决定取舍。[验收方法](references/geometry-topology-acceptance.md)
6. **结构确认后选最小工具，试一次改型。** 用原生挤出、刀切、滑环、补洞或桥接完成对应操作。平面且无布线要求的孔可保留尺寸刀体。斜交曲壳副本可借 Exact Boolean 找交线，再显式重排面带。实际改一次孔径、台肩或分缝，复查固定地标、邻件和反光。里程碑从保存工程独立重开核实。

## 工具使用规范

- 按工序查[工具工作台](references/tool-workbench.md)。编辑源笼用[网格工具逐项指南](references/tool-mesh-guide.md)。管理装配基准、分件和栈用[对象工具与原生修改器](references/tool-object-guide.md)。
- 操作前按[选区、测量和图证规范](references/tool-inspection-guide.md)锁定目标和保护区。操作后分别检查源笼、实际启用栈、成品外形或装配实剖。执行回执、目标几何与整件使用各有相应验收。
- 向技能写回可迁移的规则前，先在真实案例中重开核对。工具缺陷记录实际入口、可重复输入、表现及影响；工具边界补入相应指南。案例按已取得的证据和复现范围写入[真实产品实证](references/real-product-studies.md)。

需要调整原生修改器时，先查[基础修改器的顺序、作用范围与实剖](references/modifier-basics.md)。遇到远处卡线联动、圈缝误焊、独立物件位移错位或 UV 交接，查[进阶修改器实证](references/modifier-advanced-studies.md)。涉及多对象依赖、代理绑定、厚壳分缝、随时间求值、烘焙或导出时，查[组合修改器实证](references/modifier-composition-studies.md)。用同一个测点逐层确认实际改变的边、截面、站位或属性。交换贴合与细分、验证布尔相贯，或遇到起厚后口沿穿插时，查[布线与修改器结合实证](references/topology-modifier-casework.md)，同时复测母面误差、孔路和完整栈。

## 接到失败件时

建模时按[保存与精准回退](references/save-and-rewind.md)维护一份只读来源、当前工作件和最近通过几何验收的结构锚点。普通调参、选区预览和换视角记工序与量测；遇到未录制的破坏性编辑、阶段交接或首次不可重现操作，再保存可独立重开的锚点。受磁盘预算限制时先停整模写入，按卷核算下一次写入峰值。

需要撤回一步时，先定位第一道坏工序。已记录的多步 CLI 作业可按索引从锚点重放前缀。若后续已有手调，只撤销有旧值记录且仍能确认身份的指定源笼顶点。两条工具均先给出可核对的计划，重开候选后复测几何与保护范围。[按工序回退与按点回退的命令](references/save-and-rewind.md#选择回退方式)

保留只读原件，沿同一批保存版本找形体第一次变坏的操作。退回到它前面最近、已验证的版本，先修接线、母面或选错的点，再接回后续工序。单一合适空缺可用原生 Grid Fill（按边界铺四边格），两条已配对边界用 Bridge（在两边之间铺面）。局部移点用于调形，接错边先改连接。大面跟不上曲率或关键环连续中断时，回到少量关键截面重新搭笼。

返修点名的局部时，在单个活动网格的源笼里重新实选点、边或面，预览选区和保护范围，再动几何。按同机位核源笼及实际 L1/L2。[怎样实选和定位失效](references/mesh-flow.md#怎样实选和定位失效) · [选区与形体验收](references/geometry-topology-acceptance.md#在现有工程复查)

返边或盖槽在装配中穿插时，先固定邻件，找首次失效的工序、网格层级和截面，再决定改哪段母面或入槽方向。[沿开口续接翻边](references/mesh-flow.md#沿开口续接翻边) · [跨折面的电池盖周槽](references/real-product-studies.md#跨折面的电池盖周槽) · [前缝与双侧装配](references/real-product-studies.md#前握把合缝与镜像邻件)

## 练习和审核

从卡线间距、原生补洞和桥接，进入极点减线、缓弯面开口，再做多特征同件和陌生题。每次使用新技术先看一份原作者分步案例，记清采用了哪一段，然后在 Blender 内搭出其拓扑原理。

手里已有一个具体布线问题时，查[带实图的布线案例](references/casebook.md)中对应的一节。先辨认必须保形的截面、面带的起点与归宿、可独立调的环，再看同机位的失败版和改进版。选新案例时，确认它改变了连接方式、几何约束或可检验的改型动作。只更换造型和参数的例子可作对照。

遇到板皮成形、开槽扣臂或螺旋收尾，先从实物剖面确定保留的相连表面与真实开边，再查[成形件与接合部位的带图案例](references/formed-interface-cases.md)。

同一曲面有相邻孔、槽、筋或分片接口时，查[曲面同体多特征实证](references/combined-surface-studies.md)。按同机位复核源笼和完整 L1/L2，追踪跨缝肩线、支撑带与内翻边。改动孔、冠高、缝位或厚度后，分别复测受保护区域、可见缝和隐藏净空。

按实物教程制作可编辑白模时，查[真实产品实证](references/real-product-studies.md)。延续共用母面，按实物定位分件与运动件，单改一个开口或接触件，再查独立几何、剖面和整装。

遇到斜交鞍肩、可变扇区、周向纹理或多层止口时，查[高阶曲面相贯、闭合重复和分层接口](references/advanced-single-body-studies.md)。斜交改角时按每站剩余跨距重排圈线。焊缝先在起厚前检查组件与点距，再切成品看封壁。传面角法线前检查生成内皮和共有口沿的权重。代理变形后分别验孔路、止口间隙与沿功能方向的保高。

执行者负责工序间自检及返工。用户的两个产品评审点是关键白模和最终改型，本次基础练习独立记录。卡线、补洞等练习只认证对应能力。组合壳与陌生题各有自己的实物和审核。
