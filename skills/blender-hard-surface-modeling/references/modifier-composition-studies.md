# 组合修改器的依赖、绑定与数据流

先指定应发生变化的位置、应保持的位置，以及最终读取几何或属性的步骤。在同一份源笼上关掉一层、调换两层或只改一个控制物。每种失败都从该层的实际输入和结果定位。下文为 Blender 5.2.1 LTS 可重开的复做结果，所有工程和对照可从`逐例实证索引`进入。

## 重复件、模块与依赖

| 设计问题 | 判定方法与改型 |
|---|---|
| 同一槽要复制到所有板，还是只切一个世界板位 | 对照 Difference → Array 与 Array → Difference。前者读单块母件，后者读整排并按刀具实际位置开槽。改 Count 时量保护节距和原槽，移刀时量原位与新位置是否分别封闭和贯通。 `固定步距与移刀` |
| 多个副本共享切法，分别摆位 | 同时把主体和刀具纳入源集合。分别改实例的变换与源刀具的尺寸，用每副本自己的局部坐标量槽。关联板件共享 Mesh 时，引用同一世界刀具，第二块仍可能实心。 `集合实例与共同刀具` |
| 刀具节点读取了等待本次布尔结果的主体 | 以未切代理提供同一原网格和位置基准，刀具读取代理，主体读取求值刀具。验证代理引用和本地/世界变换。在本件循环版里刀具仍产生圆柱，主体保持无孔。分别读取刀具输出和主体通孔。 `未切代理、主体摆位和独立移刀` |
| 阵列有画面，下游没改形 | 检查实际消费者是否接收直接 Mesh。用新版 Array 的 Realize 开关对同一个后置 Bevel 或 Difference，确认实例数量、直接几何、目标截面和保护件。 `实例与下游` |
| 附加进来的是一个可用对象，还是一套可复用节点 | 用空消费文件记录 Append 当下的场景根层、依赖对象、集合和节点组，再保存冷开。试件对象路线带进宿主和 3 个对象依赖，Object Info 引用的旋钮进入根层。节点组公开输入路线起初只新增节点组。重新绑定本地对象和集合后核对实际求值。实证入口是 File → Append。 `资产库与两个消费工程` |
| 变宽弯轨上的件要保规格或同形缩放 | 用 Array → Curve → Instance on Elements 让代理面的面心和法线定位刚件。按实际网格验尺寸、站位、切向误差和横滚。有限大小的代理面在急弯处会带来位置和角度偏差。多轨先查实际分配。本例 Curve 链只消费首轨，随附新 Array 的 Per Curve 能为两轨分别布站。 `变宽和倾角的固定规格与等比试件` |

## 几何位置、面角与材质坐标

- **传法线时分别量外带、共享孔唇和孔壁。** 从无孔母体向窗口外带传自定义面角法线，固定目标网格。全传虽改善外带，试件内壁的最大转角达 98.495°。仅传外组后，内壁和孔唇的角法线保持。共享孔唇环一旦误入组，孔唇可出现 22.916° 的额外变化。保留面角数据和同位高光做对照。 `无孔导向面与限组数据`
- **同时贴面和传法线时做两开关的四组对照。** 同一控制笼量实际截面，再读取外带面角法线。此件只开 Shrinkwrap 后实剖平均差由 1.706 降至 0.148 mm。只开 Data Transfer 时截面保持原状。两步都开后外带平均角差为 0.110°。改导向面再查贴合区与 80 个固定点。 `几何和角法线的四组对照`
- **着色使用的坐标要在真实变形时验证。** 先标记需要跟随的几个源顶点，再核对属性值和渲染中的图样。Object 坐标在本件读取变形后的位置。Add Rest Position 提供变形前的局部点位。Generated 也能跟随，当前试件用原包围盒的宽度和原点恢复物理比例。 `同一剪切的三套着色坐标`
- **一件同时有搭边和返边时，先按区核对每种贴合的命中面。** 整件 Nearest 可能吸到邻近搭边，整件 Project 又可能让侧面掉到下层。给两组独立的范围，观察跨组边长度，再切面确认投射方向、上限和剔面设置。剔除不合方向的面也可能让点留在源位。 `分区贴合、错层与漏点`

## 代理绑定

- **Mesh Deform 先在希望建立的形态绑定封闭笼。** 用代理中段改型推动高密表面，并量目标区、相邻周向和端环。低模笼在本试件移 20 mm，桶的中部只凹 11.584 mm，零权重的两端保持 Ø86.400 mm。分别核对两者的位移和边界。 `金属桶几何改型`
- **中段把手参与整梁弯曲时，让 Hook 先驱动锚点。** Laplacian Deform 绑定端部和中段锚点，比较 Hook 在前、在后的同一把手行程。26 mm 行程下先 Hook 的四分点抬升 11.308 mm，最外端最大移 0.014 mm，端锚带内最大移 0.316 mm。逆序的四分点几乎不动，中段形成约 85.60° 的局部折角。共父对象移动总成，再用局部坐标复验。 `弯梁、控制器和总成移动`
- **厚件要随曲面改径，第一层绑定饰件，第二层绑定临时贴合的代理。** 在平面状态将厚件绑定到代理，开启代理的 Shrinkwrap，再把已成形的代理绑定到目标，最后关掉临时贴合。改径后分别量间隙、沿真实法线射到外皮的厚度及两端位移。本例整件直接投射让内外皮重合，在平面上完成二次绑定则留下最高 21.365 mm 的间隙。 `双层 Surface Deform 的绑定与改径`
- **只传指定的组，再限定可以接收的区域。** 在 Data Transfer 中点名源组和目标匹配，另外用目标遮罩隔开内衬或固定脚。只传 Flex 能防止 Anchor 被写入，邻近薄层仍可能串投。本例加遮罩后改代理站权重，再用实际骨骼姿态确认罩面响应与内衬位移。 `双层罩的权重串投`
- **平面孔纹先绑定展平的代理，再恢复曲面。** 关体积保持，限制 Laplacian Smooth 到所需轴并实量展平高差和固定边界。绑定后关平滑，检查真实孔口、三维孔距和代理间隙。局部网格尺寸影响本例的展平结果。半球恢复后将冠高加 6 mm，再查五个开孔和固定外圈。 `展平代理与孔纹改型`

## 厚壳、肋条与分件缝

- **Y 形共边按三臂实厚和内角穿越验收。** 同厚度对比 Solidify 的 Simple、Complex Constraints 与 Complex Fixed。三面共边应单独查超邻接边和截面交点。此件 Constraints 在距共边 25 mm 处三臂等厚，Fixed 虽闭合也在根部收窄。改一个支臂的角度后复验。 `三片共边实体化`
- **面片拆开再起厚时，分别量表层开缝和相邻壳的净距。** 截角、拆边、起厚、收边之后，先数独立闭壳，再切穿面板并检查邻件互穿。截角盒的居中起厚在表面仍有 4.555–5.162 mm 的缝，36 个邻边中点剖面却全有穿交。只改 Offset 为向外增厚后，14 片壳保住闭合与 1.031–1.302 mm 实剖净距。 `逐面薄壳与内侧净距`
- **用权重生成真实分缝时，逐层核对新点权重、删除面和缝口边。** 两段 Bevel 形成中心环及两侧插值环。让 Weight Edit 的删除阈值落在两者之间，再反选 Mask。本例边环权重低于 0.9999，中心环为 1。阈值设为 1.0 时连中心组也被移除，反选 Mask 随即保留全部面。可用首层 Bevel 调缝，接近零宽时要另验开边和保留区域。 `权重遮罩与阈值对照`
- **要留平顶肋面时，用材质索引追踪原面与倒角新面。** 先以单段 Bevel 生成平肋并写入索引，再在节点面域保留这个索引，随后起厚和轻倒角。核对槽号、实际保留面数和肋中段截面。调整主倒角宽度后，分别查平顶宽和沿法线的实厚。 `Wireframe 尖脊与倒角平肋`
- **用闭体裁平网板时，在线框化之前检查顶面、侧壁和底板。** 用与网板共用运动的平面代理写距离权重，再 Mask 保留顶面。逐帧对照实际外圈、顶面范围和离面边。本试件去掉 614 条离面边而保住当帧的 80 段外圈，改刀体后再比同一顶面的新轮廓。 `闭体裁切与距离遮罩对照`

## 运动与缓存

- **受弯的返边要在中间姿态复核内外皮。** 先对扭曲刀面明确三角线并量真实切面。由切口提取边界后，分别测试默认三角化、锁定原三角线、在可见内核补对应支点。试件静止及末帧无严格相交，锁线组仍在五个中间采样帧穿插。补点后复查截面、保留边界及改型。 `刀面对照与九帧运动复验`
- **动态权重与固定帧复制的权重用同一帧校准。** 原生 Dynamic Paint 的 Vertex / Weight 组接到 Wireframe，在同一帧读取权重、肋面面积和变化区位置。本试件四个观测帧都为 3,768 面，变化出现在肋宽和面积。改画笔时序后在副本重烘焙，关闭重开并跳帧回读。同机移目录时带上同级磁盘缓存。 `动态绘画、静态对照和缓存迁移`

## 烘焙与输出复验

- **平面浮雕近边变形时，对应检查笼与低模的面序、UV、投射方向。** 保持三角划分和笼顶高度，对比 XY 放大与等宽。按键试件等宽笼保持垂直投射，向外放大的笼在键与键之间提前命中邻键，外列图样向内偏约 5.69 mm。用实际烘焙和已知尺寸的射线见证一起定位偏差。 `平面按键投射笼`
- **多级细分先挑能保轮廓的接收层，再定最高细节层。** 核对外包、体积、UV 与边环。保留 Multires 网格和低层面序，用原生 Bake from Multires 输出切线法线或标量位移。脚本构建的细节可用同顶点顺序的高层网格通过 Reshape 写入。冷开修改底模后，对保护区和实际重烘贴图复验。 `保形低层、Multires 高层和两种原生烘焙`
- **重叠闭壳用输出副本做实并集，再让下游读取实际导出。** 核对连通件、内截面和每条边的面邻接。各壳单独闭合时仍可能有内部面，零开边时也可能有一条边连四个面。此件有正体积重叠的三个壳求并后，Trimesh 从 STL 读回单连通外壳。只接触一条棱的对照留下四面共边。 `STL 实际截面与边邻接`
- **起厚、开排口、重采样、平滑后逐层检查空腔。** 保存有原 UV 的源笼，再从 STL 查穿孔到空腔的射线、唇边壁厚和独立剖面。粗体素会改变仍贯通的口宽及最薄采样，也可能使空腔消失。窄口先关重采样定位失效步骤。 `排口、余壁及冻结 STL`
