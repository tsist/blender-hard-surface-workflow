# 从四边面带到可改的细分曲面

## 从读形到开孔的工序

1. **给几张视图约好同一把尺。** 选能跨视图辨认的角、轴心和最宽处，记下比例、原点与上下前后。正投定轮廓，侧投定深度，斜视查实际是哪层边。只有录像时，标出从确认帧可认的动作和仍需估读的尺寸。
2. **先决定分件，再为大形排点。** 给各件固定共同装配基准。若两件需要延续同一弧面，可先铺连续曲面再开缝。独立起坯也要在相同位置和姿态试配。控制站（沿形体用来定位的一点或一排点）先放在最宽处、顶峰、肩折和端部。用宽面连这些站，边走向按轮廓和截面变化安排。
3. **让早期孔口跟着大形走。** 孔口位置已知时，先放少量关键点和一圈疏边，给外围面留好接路。先检查大面和缝，再定内壁、槽底、圆角及卡线宽度。镜像适合重复左右主形，单侧特征等到确有必要时处理。Simple 可为已经确定的布线增加站位。Catmull–Clark 用于看实际抹圆后的形状。
4. **每次只接清楚的一段。** 先确认原表面上的接收边（新面实际接上的边）和父面（切线所在的原面）。用正交视图定端点，再从斜侧看前后两层。跨折返边或凹槽按桥面、斜壁、底部等各段定方向，共用相邻横边。刀切后查原面是否分成了子面，新刀边是否由两侧共用，余下自由边是否还能按预期走通。
5. **每加一道细节就复看上游造型。** 先看粗笼有没有接反，再看实际细分下的轮廓、横纵反光和关键截面。凹口逐项核开口、实际下沉、壁和底。按同一装配姿态量缝两侧，必要时查从相机出发最先看到哪块面，辨别透空、露出内皮和阴影。线越密越难改，没承担造型或接续职责的线可在副本减去，按可见差异决定。

Xbox 两集给出了两种起坯顺序。第一集先做带孔种子的前片半笼，按需用 Simple 加站，接十字键座、摇杆帽，再铺握把宽壁、分段折回，最后继续中央键、右杆和四键。第二集另起肩桥，铺出连续弯面后切出固定肩和扳机。下壳再从中央腹面与前折起步，铺内 U 弧、后桥与握把，固定上半部试配外带，然后接返边、做跨折盖周槽和前桥凹位。收尾的局部平滑与 Grab（推拉表面）用来接顺。接错的面或站位回到早期改。复杂的选边和走向先在网格上定清，脚本负责重放确认的步骤、冻结装配姿态及重复测量。原工程未取得。动作顺序依据原录像，遮挡处的深度和点位以估读记录。盖周槽按已看到的连体下壳处理，扳机行程需有额外证据才单独验。

## 先建立两族互相约束的线

以带台肩的套筒为例。沿长轴的母线决定外形如何越过台肩，绕轴的一圈决定该截面的形状。先在两端标同一物理起点，以相同段数和相位（绕一圈时，两边哪些点互相对应）桥接。沿纵向追过台肩，再横向选中闭环。发生螺旋时回到首尾对应关系，将桥接的 Twist 调回正确角点。单纯均布点距会保留错接。

- **造型环**放在截面确实改变的位置，如最宽处、主冠、安装肩或唇口。先用尽量少的站位得到正确的 L1 轮廓。
- **支撑环（卡线）**在目标转折两侧各管一道切向过渡。用 Edge Slide 沿相邻面移动一圈，观察内外两侧曲率；只给需要清晰倒圆的方向加线。三面交角尤其要查三条圆角是否以相容的宽度相遇。
- **减线与转向**从细节端向平缓区安排。极点是规则四边面内部连接边数偏离四的点。三价、五价分别指连三条、五条边，常让一圈线停下或转向。先画哪一条要贯通、哪一条要终止，调转边或重连成几个明确的四边面；把极点移离轮廓、孔角、反曲及镜面高光带。比较换位置前后的反射，按实际作用保留必要极点。
- **线距**随半径和形体变化。承托圆角的成对密线是有意设计；跨自由大面突然挤成细条，或弯折一排点只为接到另一端，则应退回截面和分段。改拓扑时可牺牲没有造型职责的行列，省下的线无需贯穿整件。

## 原生工具如何使用

| 场景 | 操作与复验 |
|---|---|
| 单一局部空缺，边界能分成两组对应边 | 只选开边。**Face → Grid Fill**，选定一个角对应的起点；用 Span 改跨向分配，Offset 旋转格的起排。检查两组新线从哪一侧进出、有无折返和翻面。遇奇数、不配对或轮廓含孔，先重新分配边界或分成几个可解释的区块。 |
| 已有圆角还需补一圈以对接段数 | 先沿目标边圈追到最近切点或肩线，选两侧都在平直区的一跨，再用 **Loop Cut**。切点附近保留原弧段的分配。对比同位 L0、L1、L2 线框、条光和关键实剖，检查是否改变了未计划改动的圆角。[插环位置对照](casebook.md#直边插线也要看被切边的邻跨) |
| 相对的两环或两条相配的开放边链 | **Edge → Bridge Edge Loops**。核对段数、起点和绕向，预览 Twist/Number of Cuts，查四边带是否错一格。桥接一对环只负责它们之间的面；套筒仍需另外设计肩线、内壁与端圈。 |
| 平顺母面上的贯穿特征 | 在基本截面阶段围出一个稀疏转接边界，以角点和切线地标建立孔环。一段对一段地接四边面。外沿 → 压线 → 内壁 → 壁背环，复测最小净宽和母面截面，留下低密度原型。盲凹沿相同原则留底。 |
| 已有正确边流，只需局部调形 | 先用原生 Edge Slide。闭合平面圆口可用 LoopTools Circle，少量通顺长链可用 Space。若试用 Relax / Set Flow，只限一个有良好邻面的已知链，固定两端与截面，比较前后。改变孔径、压薄板厚、拉坏相切时撤回。 |
| 设计阶段的生图草案 | 要求图上分清造型环、支撑环和过渡环，标出环的去向、极点位置与一个切口剖面。若画出的线无法在四边带上逐面对应，手工重画。检查以真实 Blender 源笼为准。 |

曲面产品使用上述显式连接。自动重网格、数值补片、密格裁孔和大范围 Relax 无法负责主轮廓、真实接缝或可改尺寸的设计。简单平面且无面流要求的孔可直接用布尔。斜交曲壳可在低密度闭合副本上用 Exact Boolean 定位交线，正式曲面仍按截面和地标重排面带。

异段数且锁定多对接口地标时，先数每块补片的完整周界。每个四边面贡献四次边计数，内部边各计两次，边界各计一次，所以全四边补片的边界总段数必须为偶数。若有一块为奇数，可在两块共享边界上重分段，或合并无需独立保持的分区。偶数条件通过后，还要检查短侧有无瘦长面和挤压。两安装环整圈计数相容时，也可能在局部被锁定的分区失败。[16 接 12 的四分区实证](casebook.md#异段转接先数每一区)

空间弯管除了接口绕向，还要查每道中间截面的相位。沿顶、左、右的源边从入口逐跨追到出口，留意两次弯折之间的累积偏转与近端口的突然复位。若弯到一定位置无法直接从世界轴投影得出顶向，先从实际装配或邻段给一个继续可追的相位。配对通过后再观察求值反射和最窄截面。[双急弯的实物对照](casebook.md#空间急弯的截面相位)


倾斜矩形出口的宽高应在端口自己的平面测量。先把两端的四个角配对，再接四条纵轨和侧面。改出口偏置时保护入口整环、出口尺寸、出口倾角，另读两侧角轨长度和通路。斜料斗标尺用 60 源四边面验证 600 × 300 mm → 200 × 150 mm 的四区布线，以及固定 45° 出口面下的独立偏移。展开料尺、制造公差与输送能力另验。

## 沿开口续接翻边

自由边只接一张面。折根是外皮转入返边的那条边。靠得很近的两条线可能分属不同面带，先在侧视逐条高亮来辨认。

1. 固定相邻件的安装姿态。在正投确定各站的跨度与轮廓，再用无遮挡斜视辨清重叠的边。按源笼逐段查询接收开边，每段应只有一个相邻面。已有转折被旧面盖住时，先在副本用原站位重接最小范围。若新旧站错列，检查同一四边面的两种三角剖分与实剖，识别局部翻折，再看细分反光。
2. 跨折开口按桥面、斜腿、凹底或回升分段确定挤出方向。前段已有返边时，沿剩下的开放母边接新面，并让连接处共用前一段的横边。检查这条边恰有两个相反绕向的面，剩余开边能连续选到目标。开口和端站对好后，再添加沿开口和横过面带的卡线。
3. 实际相交时，用撞点附近的截面分辨母面进深、新返边长度和邻件位置。先试只改与见证重合的自由度。需要保住正投轮廓时，可沿视线轴校局部进深，仍需另看侧视和同机位斜视。最终核源笼、实际 Mirror 与两级细分。 [Xbox 的分段接边和试装修正](real-product-studies.md#用固定邻件验证-u-形接收口)

## 单轴恒曲率件可先展开后成形

先画平展截面的外唇、侧壁、内缘与支撑环，核对每圈的点数与真实厚度。管板若为恒半径且可展开，可先在平展控制笼上构造特征，Catmull–Clark 后再用原生 Simple Deform 的 Bend。单独保留无孔母面作同半径对照，用两向条纹看宽肩，再沿实际安装轴测孔。管子整周弯曲需另外处理展开缝，并限于该缝焊接。同样的思路迁移到整周管盲槽时，先在平板上固定槽沿、给盲槽留底，再实际加深并测底厚；同时核对背缝两侧坐标、面向与高光。

在本地 16 站弯板练习中，直接在弯面加支撑时两肩会压弯条纹；24 站仍失败。用同样 638 源面换成平展开孔、细分后弯曲，两方向条纹均贴近无孔母面。孔的横向展开补偿则解决了独立的固定轴净空问题。改板长要重算 Bend 角度与半径。遇到双曲壳、变化半径或明显扭转，回到具名截面与面带，分别验证其张合与收缩。

## 怎样实选和定位失效

1. **清空并定位。** 在工作副本中核对源文件、场景、对象和活动网格。隔离目标，进入单网格编辑模式，只启用本步所用的顶点、边或面选择模式，清空旧选区。关闭细分，显示 L0 源笼。实时 Mirror 或其它修改器显示出的几何另记为求值参照。保留原标注机位，用正交侧视或斜视分辨重叠的外皮、回边和远侧。确认隐藏的对象与元素以及 X-Ray 状态。选可见外皮时关闭 X-Ray，穿透或显露遮挡区作检查后，再回到清楚可辨的机位核选区。
2. **按本次操作实选。** 在实际网格上确认高亮元素及其邻接，记清允许移动的区域和必须保住的地标。

| 选择模式 | 操作前核对 |
|---|---|
| 点 | 从目标点读一圈邻接，辨认本次应移动的点、必要过渡点和固定点。点滑移记录承接邻点与方向。肩部尖峰另量沿肩线的相邻站高差、投影跨距，以及上皮至回边的截面。 |
| 边 | 在边选择模式从可辨的种子开始。沿实际边连续走是 edge loop，跨四边面对边推进是 edge ring。记录起止或闭合、选边数、关键地标及已选边的面使用数。遇极点、非四边面或开边时，先核自动选择的实际终点，再按需要逐段补选。对于靠得很近的折线、回边根、自由边及试切线，分次高亮并从侧面追到所属面带。 |
| 面 | 核实斑块的连通分量及预期周界，明确相邻母面和需保护的孔沿、唇线或回边。做连通面内插或区域挤出前，转动视图确认背面及邻件未混入。挤出后以实剖或射线确认侧壁和新底，并核查原位置是否遗留旧盖。 |

3. **预览再操作。** 同位保存选区图，换一视角检查端点、隐藏侧和保护边。局部拖动记录实际坐标系、方向或滑移比例。融并或重连先指出要去掉的边、共享边两侧的面和应保留的边界。把源 SHA、对象、物理地标及可取得的拓扑指纹绑定到索引。重开、换件、拓扑变化或应用修改器后，以地标重选并复核，索引只在对应的源拓扑上使用。保存的顶点组可用于定位，连续路径仍须实选。[工具与交接](tool-workbench.md)

按教程复做时，核对画面高亮、工作副本里的实际选择和脚本操作的元素。把拖动预览与确认后的值分开记。确认值看不清时记为估读。保存启用了 Mirror（从半边生成对侧）或 Smooth（平滑点位）时，记录它们的实际顺序，再用诊断细分档单独定位问题。

出现折痕时，按 **连接 → 截面 → 支撑宽度 → 细分结果** 逐层检查。开正交线框和面朝向，确认环没错接；剖面下逐点看切线是否折返；再在同一位置叠 L0、L1、L2。若一级已经折起，回到最早出问题的面带。
