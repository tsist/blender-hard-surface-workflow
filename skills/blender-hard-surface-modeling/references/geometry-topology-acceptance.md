# 硬表面真实布线、流形与修改器审核

**以同位参考对照判定质量。** 审看先校准参考与模型的机位、比例、部位和状态，再逐项核可见轮廓、特征边路、曲面起伏与接收关系。复杂曲面用正交轮廓、斜视高光及关键实剖交叉确认，明确凸肩、凹区和过渡是否对应。教程实证另对照同工序源笼与实际求值。关键部位有明显偏差或证据不足时，记录具体部位、参考和观察结果，暂停该阶段放行。

**审核按布线第一、流形第二、修改器效果第三依次判定。** 每一项以实际网格和可复查证据立证。后项通过、平均分、画面漂亮或工具执行成功无法抵消前项的失败。角色命名、面数与几何指纹用于定位和回归，签收还要读任务核心意图、原始参考和真实接线。 [布线定义](mesh-flow.md#布线的基础定义)

## 开审前确认任务和真实参考

回读用户目标、约束、已知决定、参考原文及实际资产。写清本阶段要复做的结构和工序、必须保持的比例与边路、可更动的范围，以及哪些对象是正反例。教程实证回到对应步骤的原始编辑帧或作者网格。原参考只有着色图时，补取同一工序能看到线的帧。有证据的部位按同位置核对，无证据的关键部位记待证，并说明要补哪张原帧或哪个原生结构。全身远景、自动评分和历史通过表不能替代这一过程。

至少把原参考和本件的同名特征、机位、比例和姿态对齐，写明源笼还是实际细分层。原帧不能测量遮挡区的三维关系时，在记录中保留这个范围。复用父件之前在真实原参考下复验，避免把旧父件的急折或错误接收当成保护条件。

教程实证中，原参考已经看清的关键边路，必须复现其**职责、走向与归宿**。逐条比对造型环、开口边、关键卡线、极点收束和相邻面带。合理的采样调整与外围过渡可以改变，前提是同位叠线、实剖和实际求值能证实关键边路与形体仍成立。变更关键接法时，先说明偏离的位置、原因和对改型或细分效果的影响，取得确认后再继续。最终表面接近仍须满足这项要求。

## 第一门 · 布线

**布线是点、边、面的真实连接和空间排布。** 用可读的实体叠线检查接法、方向、线距与密度，不用着色图代读。每次建模取图或读图都在当前工序打开线框叠加，比较本件源笼、实际视口结果和原参考。 [叠线取证](tool-inspection-guide.md#同机位线框与逐步反馈)

| 检查项 | 可复查的合格证据 | 应退回的典型表现 |
| --- | --- | --- |
| 接法 | 在真实网格选中循环边、边环或相连面带。沿形体说明种子、跨越、转向及实际终点。孔环、连续外皮、跨段返边和相邻板的接收边在应有位置，真实邻接与可见路径对应。 | 错位连角、单独生成的格子横过预期特征、貌似接上而实际仍是两条边、同一条应连续的控制面带被无意截断。 |
| 空间排布 | 核实际截面处的点位、边向、支撑距和面带宽度。应平顺的面带沿形体变化，密度在需要控制的位置集中，退出时有明确去向。用实剖定位急折、挤窄和过渡，分清设计折棱和非预期折流。 | 顺滑的大面出现意外方向折返或窄条挤密，曲率变化处被错位卡线牵拉，极点或密度退出造成实测异常。 |
| 面型与极点 | 关键面带优先用连续四边面。三角或多边面的例外逐处说明接线职责，必须以实际细分和局部改型证明保形。极点看它如何改变或终止实际边路，并按局部曲面举证。 | 只凭全四边通过，非四边接线职责不清，极点造成圈纹、挤痕或控制带突然换向且无正反侧的证据。 |
| 可编辑性 | 每个主要布线类型至少在副本实做一次代表性改型。改一个代表尺寸，目标带连续响应。固定地标、邻件和对应曲面保持，恢复后复验。 | 一改支撑距、孔口、缝宽或肩线，未获授权的曲面随之变化，或存在形状跳变和错接。 |

真实面流用循环边、边环和相连面带检查。在面流检查入口由审核者标注原参考地标，在待验网格层实选种子，沿工具高亮确认实际边路和两端归宿。全网预扫只列待核候选。 [面流检查](tool-inspection-guide.md#面流检查)

## 第二门 · 流形与几何有效性

围绕点或边读取真实面连接。内部边为两张面实际共用，边界边有一张邻面。内部顶点邻面连成单一闭合面扇，边界顶点的面扇能够从一条边界边连续走到另一条。检查绕序、三面以上共边、断开的面扇、重复面、孤立或退化元素。原本应连续的同位边须以共享索引和邻面证明共边。不同分件的设计缝按装配证据核。

有意开放的薄片或罩片能够通过。边界须连续，面扇须连贯，并有原参考或实际截面说明开边职责。明确应闭合的实体必须闭合，另验一致绕序与实际内外层。镜像或起厚改了边界时，分别查源和真实求值层。

在同一门独立记录几何有效性。用实际非相邻面核自交，已证实的非预期严格自穿即退回。报告实际命中、对象和三角面、样本覆盖、共面与相切的检测边界。保留预期的设计接触，按结构核销。装配分别核贴座、架空、穿插、开口通路与应有净隙。 `FXX-K 灯眉实测` · `前轮窝首版的闭壳自穿` · `外饰悬空实剖`

## 第三门 · 修改器实际效果

### 确认比较的是哪一层

- **L0 源笼**读实际源点、边、面。只关细分而启用 Mirror、Smooth 等层时，单独标明这份诊断输出。
- **保存视口与实际交付档**均必查。核对象、层顺序、输入依赖、实际启用通道、档位和有效面数。二者不同就分别取证。只调 render_levels、读取面板参数或临时强制高档，都不能证明最终结果已经验证。
- **有 Catmull–Clark 的关键区**同位逐级补查 L1/L2，包括圆角、孔唇、拱肩、密度转接和极点。其余部位读实际档。实际档与一个诊断档确认为同一状态时可共用证据。用轮廓、真实截面、几何法线、视口反光和装配来找第一次变坏的层。过程保持实时线框，渲染只在最终验收。

比对同位置的关键截面、支撑带、面朝向和真实边界。检查收缩、鼓包、极点夹痕、接缝阶差、口沿变软及新自交，修改器改变拓扑后重查产生的边流与流形。 `源笼近似同形而 L2 不同的圆环`

### 核对修改器应用前后

应用前先核真实求值已满足预期，记录栈和关键形体。应用后在同场景、同姿态和同观察条件复查轮廓、关键截面、边界、共边和依赖。仍有其它修改器时核完整剩余栈。只为固化时，应用前的合格求值是对照基线。未经同意的变化退回。已获准改形则分开核许可变化和保留范围。 `轮胎 Array 与 Curve 实测`

## 记录与签收

每个关键区域记录任务意图、原参考和部位、对象与网格层、源笼或求值证据、实际命中及覆盖、判定、失败起点。使用 **通过、退回、待证、不适用**。不适用需要明确理由。主要工序或规定层证据不足时报待证，已证实的失败时报退回，当前阶段都不能签通过。阶段目标需要用户确认、或已被用户退回时，依用户决定执行。

建模者负责工序间看图和自检。独立审核按任务要求从同一保存 SHA 冷开，实际取证，并根据真实上下文与原参考判断。返修退到首次失效的母面、接边或栈层，再用新 SHA 复验相应门槛及保护区。保存普通检查的图证和数值，通过才更新对应阶段的结构锚点。 [保存与精准回退](save-and-rewind.md)

## 在现有工程复查

- 按[源笼实选流程](mesh-flow.md#怎样实选和定位失效)复查活动域、选区与保护边。点名局部的里程碑返修用改前及改后同位多宫图，显示 L0 实际选区线框、实际 L1 和实际 L2，统一取景、比例和照明。可能受实际修改器顺序影响时另看保存栈。必要时补两向条光、经过疑点的剖面和显露回边的斜视。平滑着色、材质纹理和法线转移会影响明暗判断，定位时以素模、剖面与真实边线为准。
- 核对真正改变的点坐标、边和面连接，以及受保护的邻接、边界和外部地标。局部源点固定时仍复查邻近求值曲面。需要独审时，审核者从同一 SHA 冷开，在相同源笼、场景和机位独立重取选区，报告点的一圈邻接、边路终点或面域周界，以及改前后的实际截面、轮廓或高光。严格相交检测通过只支持相交项。尖峰、间距突变和面流折返以可见形体与局部实测验收。
- 逐段复做教程时，先核当前父件上会接收新工序的边与母面，再向下做。把原帧的活动元素、实际磁盘选区和脚本操作对象逐项对齐。查看末次模态与确认后的线数、邻面和落点。若加入窄带后折光，拿添加前的真实细分图沿存档逆查，找首次明显变形的阶段。工序通过的记录应注明原课动作、对应形体与装配各已验证到哪一步。 `Xbox 对照与退回依据`
- 固定同一装配姿态，从半笼、关闭细分的实际 L0 和 CC1/CC2 中找首次失效的层级与工序。将碰撞见证定位到改动面及对应邻件，再按该处截面选返修方向。仅 L0 有穿插时，隔离 Mirror、Smooth 后复核源笼与母边。仅 CC1/CC2 有穿插时，分别开关修改器，并调出加卡线前的检查点，辨认哪一步使轮廓漂移。静态间距记录采样范围、姿态及步长。活动净空另沿真实转轴和行程检查。
- 三件交会处呈三角暗区时，用同机位的实际求值表面逐点查第一命中、部件和命中深度。可按连通域区分共用对象的固定件和活动件。随后用后正投及相邻斜视交叉核内表面外露、背景透空和贴邻表面的阴影。保留固定采样框，比较有限改形前后的可见程度，并回读静态配合。 `Xbox 固定肩角两轮对照`
- 收紧跨件外观缝时，在同一世界截面取实际求值的两条自由边，记录沿轴差量及边距。共用镜像笼时，同时取左右样本。选两侧均允许的改变量，在碰撞见证所在的保护域前衰减，再复测两侧截面、相邻固定件和同机位轮廓。源点锁定后仍复查附近的求值表面。 [Xbox 前缝返修对照](real-product-studies.md#前握把合缝与镜像邻件)
- 作业点在对象局部坐标中登记时，按保存的装配矩阵转到世界坐标再取实剖。倒角、区域内插和分割后，重取元素并核对坐标、共享边和真正改变的面。跨中线的非对称凹位须同时验证有凹位侧的内壁、对侧同位置母面、长口两端及近角。 [前桥双凹位整壳实证](real-product-studies.md#倾斜前桥的有底凹位)
- 公共 `model inspect --flow-selection` 检查指定源笼；`--geometry-audit` 可点名 source/evaluated 表示层和对象对。读返回的严格自穿、共面与跳过项的定义。装配探针需写世界毫米测点、方向与约定姿态，留意奇数交点和擦边。静态射线不能覆盖完整行程。`插件检查的输入与输出实例`
- 本技能内的 [measure_pair.py](../scripts/measure_pair.py) 可用于既有静态测量交接。试件优先以工程里的实截面、实际面数和可恢复改形动作解释问题。`实证与审核范围`

一个真实的减面取舍：双开口罩壳把窗端的局部线收在侧面，源面从 1,772 减至 1,400。顶孔、侧窗及跨窗肩线依旧满足练习，底部翻边截面却最多改变 0.503 mm。审核要把孔的功能、外观视距和翻边的配合要求分别记录。`罩壳整件减线对照`
