# 按部位审核控制笼、细分结果与改型

先写下观看距离、最暴露问题的两个角度、哪一圈要能选中，以及移动这圈时哪些地标应固定。审核者打开磁盘工程，隔离目标、关闭细分和装饰性着色。可先关闭 Optimal Display 查看求值边，取证时注明源笼或求值几何。两者分开记录。

| 放行项 | 需要现场看到 | 退回到哪里 |
|---|---|---|
| 源笼 | 两族线与截面、孔缘或肩线对应。环能按预期绕行，或在设计的极点终止。外围带没有无意义的折返、扭桥和密线。实体闭合且绕序一致；开放试片说明预期开边。 | 截面站位、周界段数或连接。全四边面仍可能接错方向。 |
| 卡线与曲面 | 同位切换 L0/L1/L2。用两个方向的反射条纹扫过冠面、角、唇和极点，检查条纹的相切、变宽和突然折回。把开口前后的母面置于同一相机和条光下，同时取经过疑点的剖线。只有开口后多出的折返或脱离指定半径的转折才回到源笼定位。 | 最早产生折线或局部凹陷的面带。用同一剖面试一次支撑环滑移。 |
| 面数与观看成本 | 记录每件源面、一级、二级实际求值面、可见实例数及目标画幅。副本去掉一圈或减一档分段，用相同机位、比例与条光比较。记录可删除的线、需保留的线及其理由。 | 无可见或可编辑收益时采用更简源笼。若省面损伤孔圆度或外角高光，给该处恢复必要分段。没有适合所有部件的统一面数或四边率门槛。 |
| 工程结构 | 取下或剖开，检查外唇、承台、内壁、缝、运动和异材件归属。通孔沿真实轴量最窄净空。若以制造为用途，依外部给定公差和壁厚。 | 拆件、剖面或装配基准。 |
| 改动与交接 | 实选环做一次有意义的规格变更。原位复核相邻带/邻件、开口贯通、剩余壁厚和两向条纹。独立重开确认源笼、修改器、顶点组选区和改型均可恢复。 | 控制层、保护区或分件设计。坐标没动的邻点附近也要检查细分后的曲面。 |

先按未起厚的求值表面验参考面偏差，再按完整栈验净空、翻边与非邻接相交。零开放边、低贴合误差和功能贯通分别立证。反常处沿截面判断是孔肩权重、圆角半径、起厚顺序或边权作用范围。调整厚度限制后复测变化处，跨拓扑对照用固定截面。 对阵列孔、分件和装配逐孔验证时，为无命中探针配邻近实体见证，查缺件或重复部件；单件开口和装配净通路分别量测。[有失败候选的实证](topology-modifier-casework.md)

审核记录用“部件／视角与表示层／证据／通过、退回或待验／回到哪一道工序”。分开记外观与结构。有遗漏的视角或测试就注明范围。技术检查通过但可见坑洼、扭曲、折痕或失控的改型仍须退回。两轮同条件无可见进步改工法；三轮无进步交用户看对照决定。基础试片的结论只在其条件内有效。

比较两种布线时，记录公共的安装口、轴线、过渡截面和目标轮廓。源尺寸相同的两版在细分后可能有不同的外轮廓。若结果将用于配合，按要求先核对求值尺寸，再将同位反射用于判断局部面流。比较局部编辑时，同时核对未动的源点和受保护边界的完整求值边线。三个管口和半球端盖都有这种实测。[带图案例](casebook.md)

多片交缝的抽样剖面用于定位。需要三片配合时，在实际细分级别补查各对整件的相交，并分别复验主缝和支缝。单片源笼保持也不保证邻缝间距保持。三片弧缝有两剖面读数已转正、完整网格仍发生相交的实测反例。[三片交缝的端角与回脚](formed-interface-cases.md#三片翻边的弧缝交会)


相邻两端的圆角补片先用短棱净跨核对源站次序。压缩后如果两端退让和超过原短棱，L0 未检出严格相交仍有可能在 L1 或 L2 形成回折。保留 L0 与使用中的实际细分档，必要时在短侧切完整实体。整件零相交也要复测每项功能。变宽弧缝查舌片投影搭接，同轴耳位查轴向净空，固定止挡的压垫沿坡连续取样。分别记录可见缝、内部距离、有效搭接和整装穿插。[相邻退让与固定开口](casebook.md#相邻角先算短棱净跨) · [变宽与压垫](formed-interface-cases.md#变宽弧缝验外观净距和搭接)

当交付要求独立审核时，由未参与制作的人从待交付的同一 SHA 冷开。逐件检查源笼和完整求值，特别核对相邻件回边的面数、顶点扇是否连通、有向体积、真实孔路与双向条光。审查发现阻断项时，单列初版的对象、位置和证据；使用新 SHA 在相同部位复验，保留本次用途仍未验的条件。

## 确认比较的是哪一层

- **源笼**看原始点、边、面与连接。关闭细分但保留 Mirror 或 Smooth 是另一种状态，记录还开着哪些修改器。
- **保存的实际结果**分别核视口与渲染中启用的修改器、顺序、细分档和实际面数。只设置 `render_levels` 时，要核细分修改器确实启用于渲染。条光、轮廓与剖面须取自标明的实际网格。
- **诊断档**在副本固定姿态和机位，按需单测 CC1、CC2（Catmull–Clark 一级、二级）。局部零严格穿插支持已检测的范围。开放壳保留设计所需的开边，靠截面、实际缝宽、首次可见面和与邻件的关系审核。动态净空另按实际转轴、用途和行程检查。

第一次见到尖峰、反光折返、错缝或穿插，就带着同一剖面回看上一份可用存档。先核选点和接边，再查母面深度及卡线。教程复做分别记录动作做到哪一步、哪些地方采用本地适配、可见形体及装配是否通过。Xbox 的后肩在错移内轨后起尖，后续握把短边在实际二级细分出现亮团。下壳外带则在同一上部装配下首次抬升时才出现扳机穿插。这些变化分别用于定位各自的回退点。

## 在现有工程复查

- 按[源笼实选流程](mesh-flow.md#怎样实选和定位失效)复查活动域、选区与保护边。点名局部的里程碑返修用改前及改后同位多宫图，显示 L0 实际选区线框、实际 L1 和实际 L2，统一取景、比例和照明。可能受实际修改器顺序影响时另看保存栈。必要时补两向条光、经过疑点的剖面和显露回边的斜视。平滑着色、材质纹理和法线转移会影响明暗判断，定位时以素模、剖面与真实边线为准。
- 核对真正改变的点坐标、边和面连接，以及受保护的邻接、边界和外部地标。局部源点固定时仍复查邻近求值曲面。需要独审时，审核者从同一 SHA 冷开，在相同源笼、场景和机位独立重取选区，报告点的一圈邻接、边路终点或面域周界，以及改前后的实际截面、轮廓或高光。严格相交检测通过只支持相交项。尖峰、间距突变和面流折返以可见形体与局部实测验收。
- 逐段复做教程时，先核当前父件上会接收新工序的边与母面，再向下做。把原帧的活动元素、实际磁盘选区和脚本操作对象逐项对齐。查看末次模态与确认后的线数、邻面和落点。若加入窄带后折光，拿添加前的真实细分图沿存档逆查，找首次明显变形的阶段。工序通过的记录应注明原课动作、对应形体与装配各已验证到哪一步。
- 固定同一装配姿态，从半笼、关闭细分的实际 L0 和 CC1/CC2 中找首次失效的层级与工序。将碰撞见证定位到改动面及对应邻件，再按该处截面选返修方向。仅 L0 有穿插时，隔离 Mirror、Smooth 后复核源笼与母边。仅 CC1/CC2 有穿插时，分别开关修改器，并调出加卡线前的检查点，辨认哪一步使轮廓漂移。静态间距记录采样范围、姿态及步长。活动净空另沿真实转轴和行程检查。
- 三件交会处呈三角暗区时，用同机位的实际求值表面逐点查第一命中、部件和命中深度。可按连通域区分共用对象的固定件和活动件。随后用后正投及相邻斜视交叉核内表面外露、背景透空和贴邻表面的阴影。保留固定采样框，比较有限改形前后的可见程度，并回读静态配合。
- 收紧跨件外观缝时，在同一世界截面取实际求值的两条自由边，记录沿轴差量及边距。共用镜像笼时，同时取左右样本。选两侧均允许的改变量，在碰撞见证所在的保护域前衰减，再复测两侧截面、相邻固定件和同机位轮廓。源点锁定后仍复查附近的求值表面。 [Xbox 前缝返修对照](real-product-studies.md#前握把合缝与镜像邻件)
- 作业点在对象局部坐标中登记时，按保存的装配矩阵转到世界坐标再取实剖。倒角、区域内插和分割后，重取元素并核对坐标、共享边和真正改变的面。跨中线的非对称凹位须同时验证有凹位侧的内壁、对侧同位置母面、长口两端及近角。 [前桥双凹位整壳实证](real-product-studies.md#倾斜前桥的有底凹位)
- 公共 `model inspect --flow-selection` 检查指定源笼；`--geometry-audit` 可点名 source/evaluated 表示层和对象对。读返回的严格自穿、共面与跳过项的定义。装配探针需写世界毫米测点、方向与约定姿态，留意奇数交点和擦边。静态射线不能覆盖完整行程。
- 本技能内的 [measure_pair.py](../scripts/measure_pair.py) 可用于既有静态测量交接。试件优先以工程里的实截面、实际面数和可恢复改形动作解释问题。

一个真实的减面取舍：双开口罩壳把窗端的局部线收在侧面，源面从 1,772 减至 1,400。顶孔、侧窗及跨窗肩线依旧满足练习，底部翻边截面却最多改变 0.503 mm。审核要把孔的功能、外观视距和翻边的配合要求分别记录。
