# 选区、测量、图证与回退

命令实例需要匹配的工作区版 Blender CLI 0.91.0。可先使用 Blender 5.3.0 原生操作和已安装插件的面板。

适用于 Blender **5.3.0** 和 Hard Surface Workflow **0.3.5**。量测按需要区分三份几何：可编辑源笼、工程实际启用的栈、为排查设置的诊断细分档。记录对象与网格、场景、视图层、帧、文件 SHA、坐标空间和单位。临时诊断要报告真实参与的 Mirror、Smooth、Subdivision 等层及面数。[工作台入口](tool-workbench.md) · [验收尺度](geometry-topology-acceptance.md)

## 锁定编辑选区

面板入口为 **3D 视图 → N → Hard Surface**。编辑模式的 **选择 → 硬表面选取** 可选边循环、边环、顶点循环、面带、范围和显式索引。先切到工具需要的单一域，实选种子和指向，绕到背面确认遮挡处的高亮及保护区。选区预览会替换当前选区。

0.3.5 面板内执行 `native.select_loop` 可能将正确的新环覆盖成预览时的旧种子。GUI 用原生环选或专用选择菜单，确认最后实际高亮。面板的保护顶点组用于保持点。要求某条边或某张面也受保护时，磁盘 `mesh.flow` 明确提交对应的 EDGE、FACE 保护选择器，并复核相邻关系。

| 入口 | 使用规则与验收 |
| --- | --- |
| 当前编辑域 / 显式索引 | 适合已经确认身份的点、边、面。保存实际成员、活动点和上下文。索引随拆面、焊接或网格重建而变，从同一保存 SHA 重开才能直接引用。拓扑指纹包括点数、有序边和面角，只验证连接。坐标变化仍可能让同一索引离开设计部位。 |
| 边循环 / 边环 / 面带 | 边循环沿相连边前进，边环跨四边面取对边。面带给一个种子面和方向边。先验证整条路径，再对保角线取样。闭环明确起点和下一站，步长为整数，`phase` 从 0 起，`limit` 包含起点并在取样前截断。遇极点、开边、隐藏区域或不成环时读终点和报错。 |
| 坐标范围 | 明确 `LOCAL` 或 `WORLD`，XYZ 边界包含端点。边、面需要所有相应点都入框，跳过隐藏元素但仍可能选到背面的可见对象网格。坐标或对象变换发生变化后重算。面板会核验范围或取样成员是否变化，公共清单若固化为 `indices` 就按原身份取点。 |
| 保存预览交给 CLI | `model panel-controls` 选 `edition=0.3.5`，在当前 SHA 上 `inspect-preview`，读取其中的执行请求并核工具和选择域。程序化连续工序走一份 `model prepare`，以单一候选保存。跨入口时先核已激活的目标、共享数据块、UV、权重和修改器引用。|

在 iPhone 七孔框上，同一颗边种子用边循环得到指定孔喉 20 边，用边环得到 68 条且只有种子重合，宽坐标框则命中五层共 132 点。用单孔闭环、每个点的层位、相邻两孔保护区一起验证，而非靠总数选对。Xbox 实测抬升后坐标框从 `[39]` 变成空，拓扑指纹完全一致。旧显式索引仍选第 39 点。

## 几何与装配检视

面板使用 **Product Surfaces and Fit → Inspect Geometry and Fit**；公共入口从 `model flow-tools --geometry-audit` 获取 JSON 参数，再交给 `model inspect FILE --expected-sha256 SHA --geometry-audit REQUEST.json`。数值以场景比例换算为世界毫米。对象名、表示层和几何预算应与当次任务一致。

| 意图 | 输入和读数 | 独立核查 |
| --- | --- | --- |
| 查自交 | `self_intersection=true`，先验指定源笼，再验实际求值。`strict_hits` 是横穿的三角对，`coplanar.overlapping_pairs` 是有正面积重叠的共面三角对。 | 按对象结果中实际出现的 `self_intersection` 字段判断是否执行。全退化输入的旧版审计结果可能报错或误报 `clear`。检查总三角数及排除数，确认至少有有效三角再采用其状态。近邻三角化密度变化后绝对计数也会变，保持对照档一致。 |
| 查两件相穿 | `pairs` 显式列两件名字，分别看严格交叉与共面重合。开放壳仍可检查表面交叉。诊断活动件时分别拆出实际连通岛或登记岛身份。 | 零交叉还要查缝宽、远近第一命中和装配侧的轮廓。若两闭件有完全包含，用实体占据和专用检测。逐姿态当前结果只适用于已验状态。 |
| 查缝宽和可见性 | `probes` 给世界毫米起点和方向，可列一个或两个闭合物件。按材料区间读取实体差距或重叠；对开放曲壳另做明示剖面或各件第一命中，再量切线附近。 | 保持共同机位、截面和可见侧，分别核活动件和固定件。切向、边角及正压在共享三角边的射线易受数值影响，用有记录的偏移做邻站复核。 |
| 查孔与贯通 | `BORE` 给孔内种子、单位方向、轴向窗口、轴向站位、最大径向搜索、角分辨率及所需轴向测线半径。分别读回算中心、中心对应的最小采样净空/对径及轴向结果。面板快速模式仅试默认 16 个方向。 | 孔壁需闭合与可判内外。简单孔测孔口、腰部、出口。规则多边孔在请求允许时用两倍边数采样来补平边测线。接近配合阈值时，切实面并量共同轴到孔壁线段的最短距，再和同站销外包半径比。轴上畅通时还要查偏轴。 |
| 测实际壁厚 | `WALL` 给接近目标面的世界毫米点、最大搜索距与最大厚度，返回吸附面、向内法向、量到的对面位置及厚度。 | 在相邻方向核最薄部位和折角。开壳、最近面法向不唯一、射线未锚定或预算不足时读明确状态。厚度值对应测点和方向。 |
| 查运动净空 | 固定其余部件，逐姿态保存轴、角度或行程，再做相交、截面、占据和净距。运动接口额外验端点之间的扫掠。 | 按样件设计取得真实轴和位移终点。静态白模与运动装配各有自己的验收依据。 |

核对配对覆盖时，逐层比对请求里的对象对与回执中实际返回的对象对，并查状态与有效三角数。`bounds_overlap_pairs` 统计通过包围盒粗筛的三角对，`tested_pairs` 只数进入横跨或共面精判的三角对。粗筛有候选但都被平面条件排除时，`tested_pairs` 可以为零。0.3.5 每次最多 16 个对象和 32 组配对，超限时错误文案可能与配对重复相同。需要拆批时固定实际场景、帧和栈，合并后按层核清单。配对缺回执或预算中止时，应保留为待验。涉及套合时，另取截面测站，确认实际净距。

规则 24 边孔的同一试件在 24 个方向恰好量到孔角，轴向半径测试全清。补采 48 个方向后，半径相同却检测到 24 条被平边挡住的射线。`clear_on_samples` 仅说明这些方向及轴向线未命中，接近装配阈值时用实际剖面和部件对复核。

高密度求值孔的 `BORE` 需单独读每个对象、每层的 `status`。三站与高角分辨率可能超过每对象每层 2,400 万次三角射线测试，即使 `model inspect` 整体成功。遇到 `unverified_measurement_budget`，在同 SHA、同场景按站拆批，保留给定的轴向窗口和角分辨率。源笼验证同时做全网格诊断。`closed_oriented_edges` 只覆盖参与三角化的边，另核孤点、松散边、顶点扇及体积分量。

`probes` 测源点两侧整条直线的材料区间。中心整线返回 `ambiguous_boundary` 时，保留该状态，并在同一剖面增取已记录的小偏移。输出区间用正负号区分两侧。核弯折孔路可从已知外部点沿连续线段量实际三角表面最近距离。用最小样本距离减半个最大采样间隔及数值余量得到这条路径的保守净空，同时用穿过实体的偏移路径复核。

## 同机位图与反馈

在对象模式 **Hard Surface → 多视角检查**，或 `model inspect --review-grid`，取同一正交中心、宽度、方向及对象成员。先用 `SOLID` 核剪影和局部倒光，再用 `CONTROL_CAGE` 与 `EVALUATED_WIRE` 核边流。求值图可临时指定 `subdivision_level` 0–3，执行前从真实求值面数和修改器启用状态确认取到目标档。视口与渲染之开关分开核，自制条光对照需确实启用渲染细分。图证融合窄处可以放大、剖切和量实线。线框预算超限会明确拒绝。iPhone 完整求值框 272,640 边，应只取要查的局部，材质和阴影可另做局部正交对照。

操作回执至少核输入和结果点数/面数、实际移动点、选区与保护区。再决定是否采纳候选。重复操作前核父 SHA、参数、插件版和已有候选。已知坏步的回退用工序前缀，单点撤销用三方坐标比较，后续其它手改优先保留。使用同一工作件和结构锚点登记，只有进入新结构里程碑时另存。[保存与精准回退](save-and-rewind.md)

本页的验收需要与案例工具问题台账一起使用。发现可复现的问题时登记实际入口、文件 SHA、错误表现、工序影响和下一步验收，据此更新使用规则。
