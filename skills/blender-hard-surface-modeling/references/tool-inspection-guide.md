# 选区、测量、图证与回退

适用于 Blender **5.3.0** 和 Hard Surface Workflow **0.3.6**。量测按需要区分三份几何：可编辑源笼、工程实际启用的栈、为排查设置的诊断细分档。记录对象与网格、场景、视图层、帧、文件 SHA、坐标空间和单位。临时诊断要报告真实参与的 Mirror、Smooth、Subdivision 等层及面数。[工作台入口](tool-workbench.md) · [验收尺度](geometry-topology-acceptance.md)

## 锁定编辑选区

面板入口为 **3D 视图 → N → Hard Surface**。编辑模式的 **选择 → 硬表面选取** 可选边循环、边环、顶点循环、面带、范围和显式索引。先切到工具需要的单一域，实选种子和指向，绕到背面确认遮挡处的高亮及保护区。选区预览会替换当前选区。

0.3.5 面板内执行 `native.select_loop` 可能将正确的新环覆盖成预览时的旧种子。GUI 用原生环选或专用选择菜单，确认最后实际高亮。面板的保护顶点组用于保持点。要求某条边或某张面也受保护时，磁盘 `mesh.flow` 明确提交对应的 EDGE、FACE 保护选择器，并复核相邻关系。`面板复现`

| 入口 | 使用规则与验收 |
| --- | --- |
| 当前编辑域 / 显式索引 | 适合已经确认身份的点、边、面。保存实际成员、活动点和上下文。索引随拆面、焊接或网格重建而变，从同一保存 SHA 重开才能直接引用。拓扑指纹包括点数、有序边和面角，只验证连接。坐标变化仍可能让同一索引离开设计部位。 |
| 边循环 / 边环 / 面带 | 边循环沿相连边前进，边环跨四边面取对边。面带给一个种子面和方向边。先验证整条路径，再对保角线取样。闭环明确起点和下一站，步长为整数，`phase` 从 0 起，`limit` 包含起点并在取样前截断。遇极点、开边、隐藏区域或不成环时读终点和报错。 |
| 坐标范围 | 明确 `LOCAL` 或 `WORLD`，XYZ 边界包含端点。边、面需要所有相应点都入框，跳过隐藏元素但仍可能选到背面的可见对象网格。坐标或对象变换发生变化后重算。面板会核验范围或取样成员是否变化，公共清单若固化为 `indices` 就按原身份取点。 |
| 保存预览交给 CLI | `model panel-controls` 选 `edition=0.3.5`，在当前 SHA 上 `inspect-preview`，读取其中的执行请求并核工具和选择域。程序化连续工序走一份 `model prepare`，以单一候选保存。跨入口时先核已激活的目标、共享数据块、UV、权重和修改器引用。 `交接用法` |

在 iPhone 七孔框上，同一颗边种子用边循环得到指定孔喉 20 边，用边环得到 68 条且只有种子重合，宽坐标框则命中五层共 132 点。用单孔闭环、每个点的层位、相邻两孔保护区一起验证，而非靠总数选对。Xbox 实测抬升后坐标框从 `[39]` 变成空，拓扑指纹完全一致。旧显式索引仍选第 39 点。`iPhone 实测` · `Xbox 复现`

### 面流检查

使用 **3D 视图 → N → Hard Surface → 面流检查**。工具读取真实点、边、面及空间位置。记录对象、源网格、场景、视图层、帧、求值层、网格指纹和世界坐标，源文件取证另带 SHA-256。检查过程用实体叠加线框和路径高亮。

1. **登记同工序原参考。** 填原参考、工序或时间码、部位和共同地标。需要图像定位时，在同一 Blender 窗口的 **图像编辑器 → N → Hard Surface → Face Flow Reference** 打开原帧并点标。回执带外部静帧文件 SHA-256、图像宽高和以左上角为原点的像素坐标。参考图变化后重新加载并点标。
2. **在本件实选或点取种子。** 源笼在编辑模式实选活动边。面带先锁定实选面，再实选其方向边。实际求值在对象模式点取，面带先点面内，再点该面的方向边中段。重合、遮挡或离边太远时改变机位、放大或核对并绑定当前层的显式索引。以种子高亮确认是否落在同一个设计地标。跨层、坐标、拓扑、对象变换、帧或隐藏状态变化时重新定位。
3. **先打开实体线框再追踪。** 实际求值层会叠加直接读取的求值网格边，超过 100,000 条边时标记超预算。边循环沿连续边前进，边环跨四边面的对边，面带按种子面和方向边跨过连续面。沿边循环返回的相邻面为侧邻接证据。对边环和面带，顺序面序列反映实际穿过的面。高亮标出种子、路径和停点。按 `steps` 实查先后、方向和真实归宿。开链查看正反两端，闭环从种子追一圈。正常到开边、极点或非四边面仍需查与参考是否同责。隐藏、多义接路、非流形和预算耗尽应从停点换视角补证。
4. **预扫给候选。** 检查可见网格，逐项定位重合分离边、断开的顶点扇、极点及方向或间距突变。纵向读相邻边长度和转角，横向读两侧相邻四边面投影到公共边垂线的宽度比。调整阈值时写入回执，保留世界坐标、实际元素和触发依据。自由边和功能卡线需根据参考解释。重合检查覆盖同一对象内端点匹配的一面边，部分重叠、不同采样和跨对象接缝需另查。查看 `coverage.unverified`、隐藏范围和省略候选计数。预扫适合作为人工逐条核查的导航。
5. **记录或清除本轮。** 使用「复制检查 JSON」保存回执，需要时保留同机位线框取证。它会重新核网格指纹。检查可以重复执行，按里程碑的保存规范持有同一工作件。

离线检查从 `model flow-tools --face-flow` 获取请求结构。通过 `model inspect FILE --expected-sha256 SHA --context CONTEXT.json --face-flow REQUEST.json` 冷开保存文件，回执为 `face-flow-report.json`。原参考四字段和种子是追踪的必填项。只预扫可提交 `{"object":"对象名","layer":"CONTROL_CAGE","scan":{}}`。首次定位核对实际元素，复用种子时提交上次 `identity.mesh_sha256`。 `EVALUATED` 读取实际视口依赖图，关键面 L1/L2、实际交付档和应用前后对照继续按审核规程取证。建议对高密度对象先追查关键种子，再按预扫范围与预算安排补充检查。

Blender 5.3.0 冷开 iPhone 七孔框，用同一条种子边复测 20 边边循环和 68 边边环，两条闭合路径只共享种子。FXX-K 原灯眉源笼检出一对重合分离边，镜像求值检出两对，修后两层均为零。原生四边网格验证开放面带停点、视口 L1 与 L0 独立定位，以及横向间距突变。 `CLI 实证` · `样件回执`

## 几何与装配检视

面板使用 **Product Surfaces and Fit → Inspect Geometry and Fit**；公共入口从 `model flow-tools --geometry-audit` 获取 JSON 参数，再交给 `model inspect FILE --expected-sha256 SHA --geometry-audit REQUEST.json`。数值以场景比例换算为世界毫米。对象名、表示层和几何预算应与当次任务一致。`请求和有效范围`

| 意图 | 输入和读数 | 独立核查 |
| --- | --- | --- |
| 查自交 | `self_intersection=true`，先验指定源笼，再验实际求值。`strict_hits` 是横穿的三角对，`coplanar.overlapping_pairs` 是有正面积重叠的共面三角对。 | 按对象结果中实际出现的 `self_intersection` 字段判断是否执行。全退化输入的旧版审计结果可能报错或误报 `clear`。检查总三角数及排除数，确认至少有有效三角再采用其状态。近邻三角化密度变化后绝对计数也会变，保持对照档一致。 |
| 查两件相穿 | `pairs` 显式列两件名字，分别看严格交叉与共面重合。开放壳仍可检查表面交叉。诊断活动件时分别拆出实际连通岛或登记岛身份。 | 零交叉还要查缝宽、远近第一命中和装配侧的轮廓。若两闭件有完全包含，用实体占据和专用检测。逐姿态当前结果只适用于已验状态。 |
| 查缝宽和可见性 | `probes` 给世界毫米起点和方向，可列一个或两个闭合物件。按材料区间读取实体差距或重叠；对开放曲壳另做明示剖面或各件第一命中，再量切线附近。 | 保持共同机位、截面和可见侧，分别核活动件和固定件。切向、边角及正压在共享三角边的射线易受数值影响，用有记录的偏移做邻站复核。 |
| 查孔与贯通 | `BORE` 给孔内种子、单位方向、轴向窗口、轴向站位、最大径向搜索、角分辨率及所需轴向测线半径。分别读回算中心、中心对应的最小采样净空/对径及轴向结果。面板快速模式仅试默认 16 个方向。 | 孔壁需闭合与可判内外。简单孔测孔口、腰部、出口。规则多边孔在请求允许时用两倍边数采样来补平边测线。接近配合阈值时，切实面并量共同轴到孔壁线段的最短距，再和同站销外包半径比。轴上畅通时还要查偏轴。 |
| 测实际壁厚 | `WALL` 给接近目标面的世界毫米点、最大搜索距与最大厚度，返回吸附面、向内法向、量到的对面位置及厚度。 | 在相邻方向核最薄部位和折角。开壳、最近面法向不唯一、射线未锚定或预算不足时读明确状态。厚度值对应测点和方向。 |
| 查运动净空 | 固定其余部件，逐姿态保存轴、角度或行程，再做相交、截面、占据和净距。运动接口额外验端点之间的扫掠。 | 按样件设计取得真实轴和位移终点。静态白模与运动装配各有自己的验收依据。 |

核对配对覆盖时，逐层比对请求里的对象对与回执中实际返回的对象对，并查状态与有效三角数。`bounds_overlap_pairs` 统计通过包围盒粗筛的三角对，`tested_pairs` 只数进入横跨或共面精判的三角对。粗筛有候选但都被平面条件排除时，`tested_pairs` 可以为零。0.3.5 每次最多 16 个对象和 32 组配对，超限时错误文案可能与配对重复相同。需要拆批时固定实际场景、帧和栈，合并后按层核清单。配对缺回执或预算中止时，应保留为待验。涉及套合时，另取截面测站，确认实际净距。 `吹风机对象对及截面实证` · `P3 拆批反例`

规则 24 边孔的同一试件在 24 个方向恰好量到孔角，轴向半径测试全清。补采 48 个方向后，半径相同却检测到 24 条被平边挡住的射线。`clear_on_samples` 仅说明这些方向及轴向线未命中，接近装配阈值时用实际剖面和部件对复核。 `三级读数与复现`

高密度求值孔的 `BORE` 需单独读每个对象、每层的 `status`。三站与高角分辨率可能超过每对象每层 2,400 万次三角射线测试，即使 `model inspect` 整体成功。遇到 `unverified_measurement_budget`，在同 SHA、同场景按站拆批，保留给定的轴向窗口和角分辨率。源笼验证同时做全网格诊断。`closed_oriented_edges` 只覆盖参与三角化的边，另核孤点、松散边、顶点扇及体积分量。 `老虎钳预算与孤点复现`

`probes` 测源点两侧整条直线的材料区间。中心整线返回 `ambiguous_boundary` 时，保留该状态，并在同一剖面增取已记录的小偏移。输出区间用正负号区分两侧。核弯折孔路可从已知外部点沿连续线段量实际三角表面最近距离。用最小样本距离减半个最大采样间隔及数值余量得到这条路径的保守净空，同时用穿过实体的偏移路径复核。 `手轮阀中心整线及三路`

只靠严格相交与正面积共面检测会漏掉同一网格中位置重合、拓扑分离的一面边。对本应同片连续的接缝，用世界坐标找重合候选，再用顶点 ID、边的面入射、方向和连通分量确认。FXX-K 灯眉修前后均为 `clear`，实际由两条单面边改为一条两面反向共边。优先在生成时共用母笼的边端 ID；既有件仅合并确认的端点。复测源笼、镜像后边界、形状和材面。跨对象的分件线接触另按装配职责审核。 `灯眉反例和公开检查回执`

## 同机位线框与逐步反馈

1. 有实时会话时在实体视口打开叠加和 Wireframe，逐张截取工作状态。进入目标件编辑模式核 L0。核实际修改器求值时按需关闭 Optimal Display、隔离对象并放大局部。以要查的活动件、相邻边和真实裁切区域为准。
2. 离线读取保存工程时，在对象模式 **Hard Surface → 多视角检查**，或先查 `model flow-tools --review-grid`，再用 `model inspect FILE --expected-sha256 SHA --context CONTEXT.json --review-grid REQUEST.json`。成对请求 `display="CONTROL_CAGE"` 与 `display="EVALUATED_WIRE"`，固定对象、`views`、`projection="ORTHO"`、`framing.center` 和 `framing.ortho_scale`。求值档默认读取实际视口栈，只有诊断档才给 `subdivision_level` 0–3。记录覆盖和改用档位。离线多视角 PNG 是插件生成的 Workbench 诊断图，过程仍以实时视口叠线为先。
3. 实际打开 `review-grid.png` 并读同回执的 `views[].display`、`wireframe.displayed_edges`、包含及遗漏。显式控制笼与显式求值线框预算分别是 50,000 与 100,000 条边，超过阈值按局部对象拆批。默认网格中某格标示线框时也可能退为实体。需要验面流时用显式模式。源半笼和实镜像只按共同可见侧对照。
4. 对照同工序原帧逐次沿环读到归宿，核布线方向、拥挤、开边和接收壁。补证时保持截面和机位。可见造型、预期贴座与几何流形分别下结论。轮廓或对应接线不合格回到工序入口。最终才用交付渲染补光影与整体外观。 `本轮公共线框实证`

工具回执供实际取证。按[硬表面审核规程](geometry-topology-acceptance.md)判定布线、流形与真实效果。操作回执至少核输入和结果点数/面数、实际移动点、选区与保护区。再决定是否采纳候选。重复操作前核父 SHA、参数、插件版和已有候选。已知坏步的回退用工序前缀，单点撤销用三方坐标比较，后续其它手改优先保留。使用同一工作件和结构锚点登记，只有进入新结构里程碑时另存。[保存与精准回退](save-and-rewind.md)

本页的验收需要与`案例工具问题台账`一起使用。发现可复现的问题时登记实际入口、文件 SHA、错误表现、工序影响和下一步验收，据此更新使用规则。
